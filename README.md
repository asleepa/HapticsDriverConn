# Setup
**Install the ViGEmBus "Virtual Gamepad Emulation Bus Driver Setup" from the Nefarius™ Project Documentation**:

https://docs.nefarius.at/Downloads/

or: https://github.com/nefarius/ViGEmBus/releases

# How to Run
Use Visual Studio or compile the C# app to an exe, and run it with the driver installed (see setup). Upon pressing CTRL+C to terminate the program, the graph will be saved to your files.

If you cannot build and run the project, download the executable from releases.
